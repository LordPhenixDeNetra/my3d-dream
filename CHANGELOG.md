## [0.1.0] - 2026-10-24

First publishable version.

### Added

- **DSH plugin** `my3d-dream`: four tools exposed to the model — `my3d_search`, `my3d_resolve`,
  `my3d_budget`, `my3d_scaffold` — and a bundle layer `cordis.patch.yml`.
- **`my3d` CLI**: `search`, `resolve`, `budget`, `scaffold`, `capture`, `stats`.
- **Knowledge corpus** in `knowledge/`: 7 records written for this project, across six domains
  (`lighting`, `material`, `composition`, `motion`, `budget`, `verification`). Every record carries
  `values`, `checks` and `limits`.
- **Precomputed BM25 index**: locked build, lazy load, automatic rebuild when the artifact is missing,
  stale or unreadable.
- **Vite + Three.js scaffold**: ACES tone mapping, sRGB color space, orbit camera, fps HUD, and a
  `window.__3DVIZ__.measure()` hook to read the engine's real costs.
- **Budget gate**: three targets (`web-desktop`, `web-mobile`, `web-vr`), validation of declared
  costs, non-zero exit on overrun.
- **Capture**: named views through Playwright; when it is absent, exit code 3 with an explicit
  message — never an invented frame.
- **Documentation**: `README.md`, `CONTRIBUTING.md`, `SECURITY.md`, `PUBLISHING.md`,
  `knowledge/README.md`.
- **GitHub Actions CI**: tests on Node 22 and 24, a guard that fails if the imported corpus is
  committed, measurement artifacts kept for 7 days.
- **Automated release**: tag `v*` → tag/version check → tests → `npm publish --provenance` →
  GitHub release with generated notes.
- **MIT license**.

### Notes

- Project at `0.x`: the tool contract and the record schema may still change.
- Published measurements (`docs/*.json`, `index/benchmark.json`) are regenerated by the test suite;
  they are not versioned.
- The corpus is deliberately small: it grows when a decision repeats, not to reach a volume.
